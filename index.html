Familiars

From blank chatbox to agent workspace.

A familiar is not a faceless bot. It has a name, purpose, memory, toolset, voice, role, and a place in a workflow that continues after the chat ends.

01 · Identity

Name the agent and define the work.

Give each familiar a clear purpose, tone, tools, and operating rules so it can show up as the right collaborator instead of a blank assistant.

02 · Memory

Keep the context that matters.

Project history, decisions, preferences, and working notes persist across sessions — continuity that's explicit, not trapped in a temporary chat.

03 · Tools

Let agents act through known surfaces.

Familiars connect to terminals, code workspaces, docs, messaging, and local runtimes through inspectable tool contracts you can review and replace.

Runtime

The local substrate underneath the Coven.

OpenCoven is not one app. It is the shared architecture for agents that remember, coordinate, use tools, and run inside boundaries builders can inspect.

/Coven

Project-scoped runtime

Launch and attach to agent work inside local repositories with visible output, history, and lifecycle control.

/OpenClaw

Tool gateway for familiars

Give agents controlled access to messages, sessions, memory, cron, media, web search, and local execution.

/CastCodes

Terminal and code workspace

Keep the command surface local-first, open, and aligned with the agents working beside you.

/Next

Adapter-ready future

The system stays harness-neutral so new agent CLIs and client surfaces can join without rewriting the whole room.

Quick Start

Run your first familiar in three commands.

Coven runs locally inside the projects you already have. Verify, start, and resume — memory persists across every session.

01 · Verify

npx @opencoven/cli doctor

Checks your environment and detects supported harnesses — Codex, Claude Code, and more.

02 · Start a session

coven run claude "fix the failing tests"

Launches a project-scoped session through Coven's managed PTY, bound to the current working directory.

03 · Resume anywhere

coven sessions

Interactive browser to rejoin, summon, archive, or view logs — work picks up where you left off.
