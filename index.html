FAMILIARS

From blank chatbox to agent workspace.

A familiar is not a faceless bot. It has a name, purpose, memory, toolset, voice, role, and place in a workflow that can continue after a single chat ends.

01 · IDENTITY

Name the agent and define the work.

Give each familiar a clear purpose, tone, tools, and operating rules so it can show up as the right collaborator instead of a blank assistant every time.

02 · MEMORY

Keep the context that matters.

Project history, decisions, preferences, and working notes can persist across sessions, making continuity explicit instead of trapped in a temporary chat transcript.

03 · TOOLS

Let agents act through known surfaces.

Familiars connect to terminals, code workspaces, docs, messaging, dashboards, and local runtimes through inspectable tool contracts you can review and replace.

RUNTIME

The local substrate underneath the Coven.

OpenCoven is not one app. It is the shared architecture for agents that remember, coordinate, use tools, and run inside boundaries builders can inspect.

/COVEN Project-scoped runtime

Launch and attach to agent work inside local repositories with visible output, history, and lifecycle control.

/OPENCLAW Tool gateway for familiars

Give agents controlled access to messages, sessions, memory, cron, media, web search, and local execution.

/CASTCODES Terminal and code workspace

Keep the command surface local-first, open, and aligned with the agents working beside you.

/NEXT Adapter-ready future

The system stays harness-neutral so new agent CLIs and client surfaces can join without rewriting the whole room.

WHY LOCAL CONTROL

Powerful without becoming opaque.

01

Boundaries stay explicit.

Agents can be useful without getting loose. Projects, commands, files, and tool access pass through visible local contracts.

02

Coordination is shared.

Dashboards, terminals, desktop surfaces, and familiars can look at the same session state instead of inventing separate loops.

03

History can survive.

Memory and logs turn useful work into continuity, while still keeping the system inspectable, local, and yours to change.

ECOSYSTEM

A living workspace of agents that belong to you.

OpenCoven turns AI from a blank chatbox into a durable workspace: familiars with memory and tools, local runtime control, open dashboards, desktop surfaces, and an ecosystem builders can inspect, customize, and own.
